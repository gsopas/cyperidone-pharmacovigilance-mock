# Cyperidone Pharmacovigilance Mock Project

## Purpose

This repository demonstrates pharmacovigilance (PV) operational capability through a mock drug safety case study built around **Cyperidone**, a fictional atypical antipsychotic designed as a structural analog of risperidone.

Cyperidone was designed from first principles using medicinal chemistry logic. It is not a real drug and no real patient data is used anywhere in this project. All cases, adverse events, and regulatory submissions are entirely fictional and constructed for educational and demonstration purposes only.

## Pharmacovigilance Competencies Demonstrated

- Individual Case Safety Report (ICSR) preparation and narrative writing
- MedDRA coding (System Organ Class, Preferred Term, Lowest Level Term)
- Seriousness and expectedness classification per ICH E2A
- Causality assessment using the WHO-UMC system
- Regulatory reporting timeline management (TGA, EMA, FDA)
- Aggregate signal detection and periodic safety reporting concepts
- Root cause analysis and risk mitigation recommendations

## About the Drug

Cyperidone is a fictional compound designed through two targeted structural modifications to the risperidone scaffold:

1. **Benzisoxazole modification**: Replacement of the fluorine atom at the 6-position with a cyano group, maintaining electron-withdrawing character while altering binding orientation
2. **Pyridopyrimidinone modification**: Extension of the methyl group at the 2-position to an ethyl group, altering metabolic handling by CYP2D6

These modifications preserve the essential pharmacophore for atypical antipsychotic activity while creating a distinct pharmacological and safety profile suitable for this educational exercise.
